## 雲端啟用尚需的帳號設定

1. Neon 管理者確認目前連線所屬 project／branch 的用途，作為 development 使用；配置獨立 runtime 與 migration 角色，避免 runtime 持有 DDL 權限。
2. 有權限的人建立 Vercel backend development Project，設定 Root Directory 與後端環境變數。
3. Repo 管理者建立 GitHub `development` environment，保存四個部署 Secrets 並啟用 `ENABLE_VERCEL_DEPLOY`。
4. push 或手動觸發 workflow，確認 GitHub CI、Vercel build／deploy 及雲端 `/health` 全數通過，將部署 URL 補入本紀錄。

這些是尚未執行的雲端操作，不標記為已完成，也不需要把 token 或資料庫密碼貼到聊天中。
